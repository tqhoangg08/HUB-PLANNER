## Implemented integration

Top header approximately 52 CSS px: Trở về, existing `/logoapp.png` HUB Planner logo, brand, Better Auth avatar/name or Đăng nhập. Session display metadata comes from the official Better Auth response; role still comes from the verified identity bridge. No Auth Worker changes. Every sidebar tab has an icon. The redundant sidebar return entry has been removed; the topbar Trở về remains. Desktop sidebar slides from 216px with icon/text to a 64px icon-only rail; the bottom toggle reverses the slide and content expands. Labels remain available through accessible link names and title tooltips. At 780px and below, a hamburger in the top-left opens a 264px left drawer with icon/text tabs, backdrop, close button, Escape dismissal, focus containment/restoration and background scroll lock. The official-session avatar or login stays at the top-right; no sidebar occupies the closed mobile layout. Inter remains inherited from global styles. White/pale blue Canva table header/striping/borders retained, with internal horizontal scroll when the authorized columns need it.

Latest owner refinement uses exactly two desktop control rows: name/MSSV, major, class; then program/type, rank, cohort. Clear and collapse sit in the top toolbar. Controls use 36px rounded pills, small labels and 8/12px gaps; removed the nested padded border to save vertical space. Semester/year remains beside the page heading. Thu gọn / Mở bộ lọc slides the dropdown area closed/open. When closed, a live name/MSSV search remains alongside Bộ lọc in the toolbar, sharing the same query/debounce/URL state as the expanded search; existing AND conditions and results remain intact. Closed controls are inert and aria-hidden; reduced-motion preference disables both sidebar and filter transitions. Mobile starts with collapsed filters and a full-width live search. Expanded filters use two columns (class/rank, major/cohort) plus the independent official scholarship program selector; clear and expand/collapse pills sit below. Keyboard order follows visual order. Mobile keeps the table with combined full name/MSSV and internal horizontal scrolling through all approved columns. The duplicate sidebar brand heading was removed; the actual topbar logo/brand remains.

Every filter is sent to recipients/search as SQL AND conditions. Search debounce remains 350ms. Changing any condition resets page; URL parameters retain active conditions and unrelated sharing parameters. Clear resets q, all five new filters, legacy category/awardType and page while preserving selected campaign and page-size preference. Changing campaign clears prior conditions. Counts are backend totals; recipient rows are fetched only by page.

Actual dropdown catalogs come from approved active-snapshot facets. Adapter paginates metadata (up to 2000 distinct options per field) without fetching all recipients. Each facet applies other filters; class options depend on program/rank/major/cohort. Pending/unsupported/error controls are disabled and explain their state, rather than pretending to filter. Selected values remain visible when a conjunction becomes empty. Incompatible/malformed/incomplete facet results fail explicitly, with no guessed production catalog.

New source fields and Admin approval choices are separate `scholarshipType`, `scholarshipRank`, `cohort`. Public table/details show them only under source approval; legacy awardType remains a legacy result label and is never used to derive the type/rank. Existing Me, celebration ownership, portrait/PNG and Admin workflows are retained.
